/ STEP 01

"ARGES, read this sign."

The user says the wake word. The microphone array detects "ARGES" locally using Porcupine — completely offline, using less than 3.5% CPU. No cloud round-trip needed.

Porcupine · Offline · <3.5% CPU
/ STEP 02

Intent parsed.

The word "read" triggers OCR mode. The 1080p camera captures a frame of whatever is in front of the user — a signboard, a medicine label, a book page.

1080p Sony Sensor · 30fps
/ STEP 03

Text extracted on-device.

Tesseract OCR runs directly on the glasses — no internet needed. It reads the sign and extracts the text in milliseconds. The AI brain handles it all locally.

Tesseract · PaddleOCR · Edge AI
/ STEP 04

Translated to your language.

If needed, the text is sent to Bhashini cloud for translation into one of 32+ Indian languages — Hindi, Tamil, Telugu, Marathi, Bengali, and more.

Bhashini · 32+ Languages
/ STEP 05

Spoken aloud.

The bone-conduction speaker delivers the answer directly into the user's ear — without blocking outside sounds. The HapticBand vibrates to confirm the task is complete.

Bone Conduction · Haptic Confirm

That's ARGES.

Voice in. Answer out. Under 1.5 seconds. Fully offline core AI. Built for India.
